# Noto fonts

Bundled for offline Latin, Romanian and simplified Chinese text rendering.

- Noto Sans Regular: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
- Noto Sans SC Regular: https://github.com/notofonts/noto-cjk/blob/main/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf

Both fonts are distributed under the SIL Open Font License 1.1. See
`NotoSans-LICENSE.txt` and `OFL.txt`, and the copyright metadata embedded in each font.
